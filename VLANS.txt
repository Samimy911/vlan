configure the port of the switch connected to a switch(S0)

> interface fa0/4
> switchport mode trunk(no restriction at all, all vlans can communicate)
> switchport trunk allowed vlan 10,20,....(for specify vlan-restricted for security purposes)
> show interfaces trunk
> exit





        


configure the router(R0) for inter-vlans(10,20,30) communications


> interface g0/0.10
> encapsulation dot1Q 10
> ip address 192.168.10.1 255.255.255.0
> exit


> interface g0/0.20
> encapsulation dot1Q 20
> ip address 192.168.20.1 255.255.255.0
> exit


> interface g0/0.30
> encapsulation dot1Q 30
> ip address 192.168.30.1 255.255.255.0
> exit

no shut

Configuring dynamic routing(RIP)

(On the left router / first router)

> enable
> configure terminal

> interface fa0/0
> ip address 192.168.10.1 255.255.255.0
> no shutdown

> interface se2/0
> ip address 192.168.30.1 255.255.255.252
> clock rate 64000      ← ONLY if this side is DCE
> no shutdown


>router rip
> version 2
>no auto-summary
>network 192.168.10.0
>network 192.168.30.0


(On the right router/second router)


>enable
>configure terminal

>interface fa0/0
>ip address 192.168.20.1 255.255.255.0
> no shutdown

>interface se2/0
>ip address 192.168.30.2 255.255.255.252
>no shutdown

(On right side router)
>router rip
>version 2
> no auto-summary
>network 192.168.20.0
>network 192.168.30.0
