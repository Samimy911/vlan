inter-Vlan(A switch and router)
*** A switch connected to many computers
*** A router is connected to the switch or the switch is connected to a router

#switch

> enable
> configure terminal

> vlan 10
> name Sales
> exit

> vlan 20
> name HR
> exit

> vlan 30
> name IT
> exit

#configure assigned ports of pcs connected to switch

> interface range fa0/1-2
> switchport mode access
> switchport access vlan 10
> exit


> interface range fa0/3-4
> switchport mode access
> switchport access vlan 20
> exit

> interface range fa0/5-6
> switchport mode access
> switchport access vlan 30
> exit




configure the port of the switch connected to router on the switch(S0)

> interface fa0/4
> switchport mode trunk
> exit

configure the router(R0) for inter-vlans(10,20,30) communications


> interface g0/0.10
> encapsulation dot1Q 10
> ip address 192.168.10.1 255.255.255.0
> exit


> interface g0/0.20
> encapsulation dot1Q 20
> ip address 192.168.20.1 255.255.255.0
> exit


> interface g0/0.30
> encapsulation dot1Q 30
> ip address 192.168.30.1 255.255.255.0
> exit

 
configure DHCPS pools on router(to get automatic IPS)

> ip dhcp pool vlan 10
> network 192.168.10.0 255.255.255.0
> default-router 192.168.10.1
> exit

> ip dhcp pool vlan 20
> network 192.168.20.0 255.255.255.0
> default-router 192.168.20.1
> exit


> ip dhcp pool vlan 30
> network 192.168.30.0 255.255.255.0
> default-router 192.168.30.1
> exit

Trunk port: switch port-number toward the router(switch-0)

> interface fa0/3
> switchport mode trunk
> switchport trunk encapsulation dot1q
> exit

how to configure two routers connected to each other and  two switches each connected to each router and each switch connect to 2 computers


R1
==
enable
confi t
int gi0/0
ip add 192.168.10.1 255.255.255.0
no shut
int gi0/2
ip add 192.168.20.1 255.255.255.128
no shut
int gi0/1
ip add 10.10.10.1 255.255.255.252
no shut

no shut

how to configure bgp


router bgp 100
bgp router-id 1.1.1.1
neighbor 10.10.10.2 remote-as 200 
network 10.10.10.0 mask 255.255.255.0
network 192.168.10.0 mask 255.255.255.128


router bgp 200
